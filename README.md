# Задача: Система аутентификации по телефону с инвайт-кодами

## Описание

Данный сервис реализует REST API для аутентификации пользователей по номеру телефона с использованием одноразовых кодов, а также поддерживает систему инвайт-кодов (реферальную программу). Для аутентификации используется JWT-токен.

---

## Основные требования

- Отправка одноразового 4-значного кода для входа по номеру телефона
- Верификация кода и получение JWT-токенов (access и refresh)
- Автоматическое создание пользователя при первом запросе кода
- Генерация уникального инвайт-кода для каждого пользователя
- Возможность активировать чужой инвайт-код (один раз)
- Просмотр профиля пользователя и списка его рефералов
- Защита эндпоинтов, требующих авторизации, с помощью JWT

---

## API спецификация

### POST `/api/send_code/`

- Принимает: `phone_number` (строка)
- Поведение: отправляет одноразовый код, создаёт пользователя при необходимости
- Ответ: `{ "code": "<4-значный код>", "message": "Код для входа" }`

### POST `/api/verify_code/`

- Принимает: `phone_number`, `code`
- Поведение: проверяет корректность кода, возвращает JWT-токены
- Ответ: `{ "refresh": "<refresh_token>", "access": "<access_token>" }`

### GET `/api/profile/`

- Требует авторизации (JWT access token)
- Возвращает данные пользователя:
  - `phone_number`
  - `invite_code`
  - `activated` — код инвайта активировавшего пользователя
  - `referals` — список номеров телефонов приглашённых пользователей

### POST `/api/activate-invite/`

- Требует авторизации (JWT access token)
- Принимает: `invite_code`
- Поведение: активирует инвайт-код другого пользователя (один раз)
- Ответ: сообщение об успехе или ошибке

## Техническая реализация

- Используется Django  и Django REST Framework
- Аутентификация реализована через `djangorestframework-simplejwt`
- Для валидации номера телефона используется минимальный сериализатор `CodeSerializer`
- Логика генерации кодов реализована в отдельной функции
